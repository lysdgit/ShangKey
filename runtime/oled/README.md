# ShangKey 小屏（ESP8266 + SSD1306）接线与使用说明

让键盘旁边的 128x64 小屏实时显示打字内容：拼音串、候选词、中英状态。
打字时不用抬头看显示器。

---

## 1. 工作原理

```
   电脑 (ShangKey IME)                      小屏 (ESP8266 + SSD1306)
   ┌──────────────────────┐                ┌────────────────────────┐
   │ rime 引擎产出候选    │                │ ① UDP 广播找电脑        │
   │   ↓                  │   ② HTTP 拉帧 │ ② HTTP GET /frame.bin  │
   │ PIL 渲染 128x64 位图 │ ────────────> │ ③ 按页写进 OLED 显存    │
   │   ↓                  │  1024 字节    │                        │
   │ HTTP :61824          │                └────────────────────────┘
   │ UDP :61825 自动发现  │
   └──────────────────────┘
```

**为什么画面在电脑上渲染？**
SSD1306 是纯位图屏，一帧正好 1024 字节，天然是「页序」布局。所以电脑上用
PIL 把界面画好推过去，小屏只当显示管子。好处很实在：

- 固件**零第三方库**（只用 ESP8266 core 自带的 WiFi / HTTP / Wire）
- 不用装 U8g2、不用烧中文字库，Arduino IDE 装好 ESP8266 开发板包就能编译
- 中文用微软雅黑/黑体渲染，比点阵字库好看得多
- 以后想加内容（已上屏文本、更多候选）只改电脑端，不用重新烧固件

## 2. 硬件清单

| 部件 | 说明 |
|---|---|
| ESP-01S | ESP8266 模块，8MB flash 版本也可（够用） |
| SSD1306 OLED | 128x64 单色，I2C 接口，4 脚（VCC/GND/SCL/SDA） |
| 杜邦线 | 4 根 |
| 3.3V 电源 | ESP-01S 无 3.3V 输出，OLED 供电要单独给 |

> **注意**：ESP-01S 只有 8 个引脚，可用 GPIO 很紧张。
> 如果你手上有 ESP-12F / NodeMCU，接线更宽松（GPIO4=SDA、GPIO5=SCL 即可）。

## 3. 接线

ESP-01S 引脚（从模块顶端开始数）：

```
      ┌──────────┐
  1   │      EN  │  3.3V
  2   │    GPIO2  │  ───► SDA   (I2C 数据)
  3   │    GPIO0  │  ───► SCL   (I2C 时钟)
  4   │    GPIO15 │  ───► (不用)
  5   │    GND    │  ───► GND
  6   │    GPIO3  │  ───► (不用)
  7   │    GPIO2  │  ───► (备用)
  8   │  3V3/VCC │  ───► VCC
      └──────────┘
```

| ESP-01S | SSD1306 | 说明 |
|---|---|---|
| 3V3 / VCC | VCC | 3.3V 供电 |
| GND | GND | 共地 |
| GPIO2 | SDA | I2C 数据 |
| GPIO0 | SCL | I2C 时钟 |

**两个坑要注意：**

1. **GPIO0 兼作启动模式选择脚**。烧录固件时需要把它拉低（进下载模式），
   烧录完就是普通 GPIO，接 I2C 时钟没问题。但如果你的 OLED 模块的
   SCL 带上拉电阻（大多数模块都带 4.7K 上拉），可能导致模块上电时
   误进下载模式。**遇到上电不启动，把 SCL 改接 GPIO4**
   （改固件顶部的 `SCL_PIN` 常量即可）。
   烧录时也可以临时把 SCL 线拔掉，编译好再插上。

2. **ESP-01S 没有 3.3V 输出能力**。OLED 供电要单独接 3.3V，
   电流至少 20mA。ESP-01S 本身吃电峰值能到 300mA，电源要留够余量，
   否则 WiFi 发射瞬间电压跌落会重启。

## 4. 烧录固件

1. 装 [Arduino IDE](https://www.arduino.cc/en/software)
2. 在「文件 → 首选项 → 附加开发板管理器网址」填：
   `https://arduino.esp8266.com/stable/package_esp8266com_index.json`
3. 「工具 → 开发板 → 开发板管理器」搜 `esp8266`，安装
4. 「工具 → 开发板」选 **ESP8266 Generic (1MB)**（4MB flash 选对应项）
5. 打开 `ShangKeyOLED.ino`
6. 改文件顶部的两个参数：
   ```cpp
   static const char* WIFI_SSID = "你的WiFi名字";
   static const char* WIFI_PASS = "你的WiFi密码";
   ```
   `FIXED_PC_IP` 留空即可（走自动发现）；如果你的路由器不让广播，
   就填上电脑的固定 IP。
7. 连接 ESP-01S 的 USB-TTL（注意：TX/RX 交叉，3.3V 电平）
8. 点上传。烧录时 GPIO0 接 GND，成功后断开

**库依赖：无。** 全部来自 ESP8266 core 自带。

## 5. 电脑端设置

### 5.1 放行防火墙（必做）

Windows 防火墙默认拦截入站连接，小屏会拉不到帧。以**管理员身份**打开
PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "ShangKey OLED" -Direction Inbound -LocalPort 61824 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "ShangKey OLED Discovery" -Direction Inbound -LocalPort 61825 -Protocol UDP -Action Allow
```

不想开防火墙也行：把固件里 `FIXED_PC_IP` 填成 `127.0.0.1` 没用（那是回环），
正确做法是**在同一台电脑上用 USB 串口方案**，或者在路由器里给电脑做
IP 绑定 + 关闭 AP 隔离。

### 5.2 启动输入法

正常运行 ShangKey 即可，小屏服务默认开启。托盘菜单里有：

- **「OLED 小屏服务」** —— 勾选/取消可随时开关小屏服务
- 调试时浏览器打开 `http://电脑IP:61824/` 能看到实时画面

### 5.3 环境变量（可选）

| 变量 | 作用 | 默认 |
|---|---|---|
| `SHANGKEY_OLED_HOST` | 监听地址，改成 `127.0.0.1` 只允许本机 | `0.0.0.0` |
| `SHANGKEY_OLED_PORT` | HTTP 端口 | `61824` |
| `SHANGKEY_OLED_TOKEN` | 加 token 校验，需 `?token=xxx` | 空（不校验） |
| `SHANGKEY_DISABLE` | 加 `oled` 可完全禁用 | 空 |

> **安全提醒**：开着小屏服务时，同一局域网内的任何设备都能看到你的
> 输入内容。公共 WiFi 下建议设 `SHANGKEY_OLED_TOKEN`。

## 6. 屏幕布局

```
┌────────────────────────┐
│ ni hao                 │  ← 拼音串
│ 1 你好      2 妳好     │  ← 候选（两列三行）
│ 3 逆号      4 拟好     │     第 1 个反白高亮
│ 5 你                    │
│ 中                URL  │  ← 状态行
└────────────────────────┘
```

- 高亮候选 = 白底黑字（反白），与电脑端观感一致
- 最多显示 6 个候选
- 右下角小字是切换来源（URL / 手动 / 规则名）
- 英文模式下拼音区为空，只剩状态行显示「英」

## 7. 排查

| 现象 | 原因 / 处理 |
|---|---|
| 屏幕全黑 | 没收到帧。检查电脑端服务是否启动、IP 是否对、防火墙 |
| 屏幕有闪烁边框 | 正常，说明还没找到电脑（等待中） |
| 串口打印「取帧失败」 | 电脑 IP 变了或服务被关。等 5 秒会自动重新发现 |
| 串口打印「发现电脑: x.x.x.x」 | 网络通了，接下来看能否取到帧 |
| 上电不启动（模块反复重启） | 电源供电不足，或 GPIO0/SCL 冲突（改接 GPIO4） |
| 画面左右镜像 | 极少数模块的列寻址不同，把固件 `oledFlush()` 里 `0xA1` 改成 `0xA0` |
| 画面上下颠倒 | 把 `0xC8` 改成 `0xC0` |
| 中文显示成方块/乱码 | 固件不做字体渲染，出现此问题说明是接线或数据错位，重查 I2C |

**调试小技巧**：把电脑上的 `runtime/oled_preview.png` 打开，
那是当前小屏该显示的样子（PNG 预览与实际屏幕一致）。

---

## 8. 关机 / 休眠注意

小屏常亮会耗电（ESP8266 约 80mA，OLED 约 20mA）。如果不需要的时候
想让它休眠，可以在固件里加个「N 分钟无输入就关屏」的逻辑——目前版本
是常亮的。
